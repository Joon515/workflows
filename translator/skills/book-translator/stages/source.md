# Stage 0: evidence and source structure

Read [format.md](../references/format.md) and complete explicit model intake and native configuration in [operation.md](../references/operation.md) before source authoring. The coordinator runs doctor, initializes a fresh job and extracts evidence, then dispatches ordinary native book-source work with nonempty top-level context and per-item task/solutionSpace identifying the job, instructions, packet/result paths and write boundaries. Use the exact user-selected source model configured through standard OMP agent frontmatter or native agent-model overrides; configure-model records book intent but does not route tasks. More than eight source pages requires durable source units: write only the assigned result/assets, never canonical source/book or sibling results; the controller alone assembles. Eligible whole-role work of at most eight source pages writes its assigned canonical source. Do not initialize or overwrite an existing job. The coordinator owns native API argument completeness and native model configuration; the worker acts from the clear rendered assignment and does not need the raw parent context/task/solutionSpace JSON, host credentials or hidden model introspection.

Visually inspect every source page in the entire assigned unit or small whole-role scope and all applicable extraction warnings. Record page-specific inspection evidence; text extraction, draft imports and a few sampled images cannot establish visual coverage. Every imported draft page remains pending until its unit is inspected and admitted. Fresh-extraction unit planning may supply an unreviewed OCR/page skeleton as a baseline; it is not a ready manuscript. Reflow page indices and metadata page labels are not printed pagination. Transcribe printed labels only from actual source images/page-list anchors with provenance. Keep unnumbered pages null, Roman labels and repeated labels intact. Put page tokens at exact source boundaries, including inside a paragraph. Do not infer a sequence across a missing page. A blank or failed first image preview does not establish a blank or unavailable source page: before reporting source unavailable, try the already available original PDF page, retained raster or an inspection crop with ordinary tools. Preserve original evidence and output-artwork integrity; this is an inspection attempt, not permission to crop/split book artwork or claim uninspected coverage.

Keep the exact ordered original extraction locators and unique source-page IDs/locators. A small whole-role source may rename IDs only while preserving that ordered locator inventory; unit results conserve their prepared owned IDs/locators. Controller-recorded extraction identity must remain current through admission/sealing. Missing or changed journaled extraction is a blocker, not permission to substitute a different inventory or claim visual proof from matching hashes.

Reconstruct the entire assigned version-2 source scope in the assigned result using paragraph/block IDs, source-page mappings, page evidence, native/OCR text and embedded images. Do not leave OCR scaffolding or omit difficult material because other units remain pending. Follow the canonical title/body-start ownership contract below; never invent a body start per unit. Represent ordered/unordered material as list_item blocks with original labels and nesting; do not flatten it into unindented paragraphs. Classify actual source blank pages as blank blocks with evidence, not explanatory placeholder prose; do not discard sparse real content. Correct OCR against the page, including punctuation, formulas, superscripts and code whitespace. Every paragraph, caption, heading, table and note in scope needs accounted-for reading order. Declare formulas, variables, literal code including comments and personal/eponym names as protected content, preserving literal values and evidence. Preserve cross-unit boundary identity/order under the canonical result contract.

For a fresh unknown body boundary, only the unit observing the actual first main-body content declares optional top-level body_start, naming a nonblank block that it owns and returns. A later chapter start is not another body_start. If packet.metadata.main_body_start is null, the metadata owner may omit that field or leave it null while supplying the title; never guess an unseen remote boundary. Other units may declare body_start without becoming metadata writers. The controller reconciles all candidates and requires exactly one unique existing boundary before assembly; zero/conflicting candidates block rather than triggering an automatic first-heading/page guess. Known-draft metadata behavior remains unchanged.

At unit seams, read the packet's neighboring context_blocks/context_notes and declared ownership/protected data as read-only evidence. Reconcile carry-over text, notes, images and protected references across the boundary without re-authoring a neighbor's content or counting it twice as newly owned prose. Use the canonical per-page semantic-ID declaration contract; it records the model's claimed coverage, not independent proof that an image was perceived or proofread. Visual inspection of every owned page remains required. If reconstruction introduces cross-unit structure unsupported by the prepared packet, keep the affected work explicitly pending and request coordinator replanning; never omit the structure, truncate a crossing block or manufacture a successful result. No new geometric-span annotation is required.

Every prepared outgoing_block_id must remain in the assigned result with exactly its prepared source_pages. Do not remove it, shorten it to the first owned page or replace it with local prose to avoid the crossing rule. If its structure needs to change, preserve the authored work and return the explicit pending/replan blocker; do not claim the unit complete.

Default to reconstructing damaged prose when source context or a verifiable independent witness supports a defensible reading. Distinguish confirmed and conjectural readings in immutable internal restoration metadata; context is evidence, not recovered ink. Follow the canonical restoration-note contract: place the replacement immediately before its single editorial callout, record the original fragment, source-page identity, replacement, status and supporting rationale/evidence internally, and include the supplied-source damaged crop as a visible inline image in the prose note. A cleaner witness is supporting evidence, never a substitute for that damaged crop. The original fragment must remain verbatim in both source and translated note. Author only a concise completion notice alongside that excerpt and crop; do not print a source-page locator, repeated replacement, confirmed/conjectural status, rationale or other commentary. The translated note keeps this minimal visible content in note.target; the renderer does not automatically print restoration metadata. Do not present uncertain numbers, units, formulas, identifiers or table values as certain. If those technical details cannot be corroborated, or no defensible prose reading exists, retain the uncertainty and stop the affected source handoff for resolution rather than inventing content.

Use reviewed protected LaTeX for formulas only after verifying every symbol against source evidence; otherwise preserve the actual formula image. Do not claim a native table renderer or automatic table reflow: the current implementation has neither. Use immutable inline image tokens for raster mathematics or variables embedded within prose; record original dimensions, the source font em for that actual inline context and baseline alignment. Every displayed image/group also needs source_em in its canvas coordinate units and scale_evidence identifying the normal surrounding source running-text/body font, not a smaller diagram-label or caption font. Prefer native font measurements where exposed; OCR/DjVu bbox height or raster DPI is not font em. Missing calibration blocks source readiness rather than enabling fit-to-page scaling. Original raster-contained note markers remain unchanged, with a visually verified canonical callout association where relocation is needed.

Classify every note as prose or literal. Explanatory notes must be translated even when their original was a raster: transcribe readable source prose, preserve the complete original note image in non-rendered source_evidence with source-page/marker/association details, and reserve ordinary output image tokens for non-prose mathematics/figures. The declared original damaged crop in a restoration note is the narrow rendered-evidence exception, not permission to pass untranslated explanatory prose through as an image. Separate mixed-note prose from protected formula/code/name content. A literal note needs a truthful literal_reason; do not classify an English explanatory sentence as literal merely to conserve its bitmap. Resolve damaged prose through the restoration policy above; uncertain callout association still blocks source readiness.

Capture nearby text and images into side-text groups when the image is left/right of that paragraph. Multiple images use a shared canvas and original x/y/width/height, not separate floats. Keep before/after relationships and captions. Source-em geometry defines the preferred output size, not automatic full-column/page fill. Source-only documents must omit output-only fit metadata. The translation stage may make a bounded, explicitly reviewed uniform downscale under format.md without altering source calibration; absent that output choice, the preferred scale is unchanged. Never crop or split an intact image/group, enlarge it to fill space, or silently change paper or margins. Preserve the original file and full source-page images so review can challenge grouping, scale, blank classification and note transcription.

Return the complete assigned source result and per-page inspection evidence through the native task. The source object may have empty target arrays and empty agent_preface. The coordinator waits for native task settlement, checks actual result identity and checkpoints the book result with checkpoint-unit or checkpoint-role as applicable. A unit checkpoint changes no canonical source, seal, whole-book state or round. The controller assembles only when every planned page/unit has complete checkpointed coverage; the coordinator then validates the initial unsealed source and runs seal-source separately. Uncheckpointed or partially assembled source cannot be sealed. Sealing records complete authorized-source extraction coverage, reading order, source-page provenance, restoration notice/excerpt/crop and internal metadata, and protected-span checks; OCR alone and sampled pages are insufficient. Checkpoint identity is native operator metadata and book-progress bookkeeping, not independent proof of engine authentication or visual inspection.
