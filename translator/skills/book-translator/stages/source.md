# Stage 0: evidence and source structure

Read ../references/format.md. Run doctor and initialize a fresh job; never overwrite an existing job or silently replace source evidence. Run extraction with auto OCR by default. A missing OCR or DjVu dependency is a blocker for affected inputs, not permission to skip the required path. Use `--ocr always` for unreliable hidden text; `--ocr never` is an explicit evidence-only mode, not proof scans are recognized.

Inspect every source page and the extraction warnings. Reflow page indices and metadata page labels are not printed pagination. Transcribe printed labels only from actual source images/page-list anchors with provenance. Keep unnumbered pages null, Roman labels and repeated labels intact. Put page tokens at exact source boundaries, including inside a paragraph. Do not infer a sequence across a missing page.

Reconstruct book-source.json using paragraph/block IDs, source-page mappings, page evidence, native/OCR text and embedded images. Correct OCR against the page, including punctuation, formulas, superscripts and code whitespace. No invented reconstruction. Every source paragraph, caption, heading, table and note needs accounted-for reading order; tables can be reviewed image assets when faithful text reconstruction is not possible. Preserve tables as indivisible groups when needed. Declare all formulas, variables, code blocks including comments and personal/eponym names as protected entries. Use image assets for formulas that cannot be reliably transcribed. Missing/ambiguous source remains a blocking finding, never a guessed sentence.

Capture nearby text and images into side-text groups when the image is to the left/right of that paragraph. Multiple images use a shared canvas and their original x/y/width/height, not separate floats. Keep before/after relationships for vertical content and image captions. Move a whole group to another page if necessary; sparse text or an image-only output page is acceptable. Never crop or split an image between pages. Preserve the original source file and full source page images so review can challenge the grouping.

Source work ends only after source-only validation and seal-source. The source object may have empty target arrays and empty agent_preface. Sealing is a deliberate assertion that extraction coverage, reading order, source-page provenance and protected spans were checked, not a claim that OCR is inherently reliable. If a later correction is needed, run seal-source --reseal explicitly, regenerate downstream artifacts and invalidate all previous build/review acceptance. Submitted review pairs are archived for audit; an unchanged reseal cannot reset the round cap. Do not change source structure in the translation stage.
