# Stage 0: evidence and source structure

Read [format.md](../references/format.md) and complete model intake and the native role flow in [operation.md](../references/operation.md) before source authoring. The coordinator runs doctor, initializes a fresh job and extracts evidence; the prepared book-source task receives that existing job and must not initialize or overwrite it. Use the exact source provider/model selected for this workflow. Use auto OCR by default. A missing OCR or DjVu dependency blocks affected inputs, not permission to skip the required path. Use --ocr always for unreliable hidden text; --ocr never is an explicit evidence-only mode, not permission to skip necessary OCR.

Inspect every source page and the extraction warnings. Reflow page indices and metadata page labels are not printed pagination. Transcribe printed labels only from actual source images/page-list anchors with provenance. Keep unnumbered pages null, Roman labels and repeated labels intact. Put page tokens at exact source boundaries, including inside a paragraph. Do not infer a sequence across a missing page.

Reconstruct version-2 book-source.json using paragraph/block IDs, source-page mappings, page evidence, native/OCR text and embedded images. Explicitly identify main_body_start from the verified frontmatter/body boundary. Represent ordered/unordered material as list_item blocks with original labels and nesting; do not flatten it into unindented paragraphs. Classify actual source blank pages as blank blocks with evidence, not explanatory placeholder prose; do not discard sparse real content. Correct OCR against the page, including punctuation, formulas, superscripts and code whitespace. Every paragraph, caption, heading, table and note needs accounted-for reading order. Declare formulas, variables, literal code including comments and personal/eponym names as protected entries.

Default to reconstructing damaged prose when source context or a verifiable independent witness supports a defensible reading. Distinguish confirmed and conjectural readings in immutable internal restoration metadata; context is evidence, not recovered ink. Follow the canonical restoration-note contract: place the replacement immediately before its single editorial callout, record the original fragment, source-page identity, replacement, status and supporting rationale/evidence internally, and include the supplied-source damaged crop as a visible inline image in the prose note. A cleaner witness is supporting evidence, never a substitute for that damaged crop. The original fragment must remain verbatim in both source and translated note. Author only a concise completion notice alongside that excerpt and crop; do not print a source-page locator, repeated replacement, confirmed/conjectural status, rationale or other commentary. The translated note keeps this minimal visible content in note.target; the renderer does not automatically print restoration metadata. Do not present uncertain numbers, units, formulas, identifiers or table values as certain. If those technical details cannot be corroborated, or no defensible prose reading exists, retain the uncertainty and stop the affected source handoff for resolution rather than inventing content.

Use reviewed protected LaTeX for formulas only after verifying every symbol against source evidence; otherwise preserve the actual formula image. Do not claim a native table renderer or automatic table reflow: the current implementation has neither. Use immutable inline image tokens for raster mathematics or variables embedded within prose; record original dimensions, the source font em for that actual inline context and baseline alignment. Every displayed image/group also needs source_em in its canvas coordinate units and scale_evidence identifying the normal surrounding source running-text/body font, not a smaller diagram-label or caption font. Prefer native font measurements where exposed; OCR/DjVu bbox height or raster DPI is not font em. Missing calibration blocks source readiness rather than enabling fit-to-page scaling. Original raster-contained note markers remain unchanged, with a visually verified canonical callout association where relocation is needed.

Classify every note as prose or literal. Explanatory notes must be translated even when their original was a raster: transcribe readable source prose, preserve the complete original note image in non-rendered source_evidence with source-page/marker/association details, and reserve ordinary output image tokens for non-prose mathematics/figures. The declared original damaged crop in a restoration note is the narrow rendered-evidence exception, not permission to pass untranslated explanatory prose through as an image. Separate mixed-note prose from protected formula/code/name content. A literal note needs a truthful literal_reason; do not classify an English explanatory sentence as literal merely to conserve its bitmap. Resolve damaged prose through the restoration policy above; uncertain callout association still blocks source readiness.

Capture nearby text and images into side-text groups when the image is left/right of that paragraph. Multiple images use a shared canvas and original x/y/width/height, not separate floats. Keep before/after relationships and captions. Source-em geometry defines the preferred output size, not automatic full-column/page fill. Source-only documents must omit output-only fit metadata. The translation stage may make a bounded, explicitly reviewed uniform downscale under format.md without altering source calibration; absent that output choice, the preferred scale is unchanged. Never crop or split an intact image/group, enlarge it to fill space, or silently change paper or margins. Preserve the original file and full source-page images so review can challenge grouping, scale, blank classification and note transcription.

Return the complete source manuscript and inspection evidence through the prepared native task. The coordinator must finish and admit that task, validate the initial unsealed source and run seal-source separately; an unreceipted source cannot be sealed. The source object may have empty target arrays and empty agent_preface. Sealing asserts that extraction coverage, reading order, source-page provenance, restoration notice/excerpt/crop and internal metadata, and protected spans were checked; OCR output alone is not that evidence. For a correction to sealed source, the coordinator first prepares source revision under operation.md. Read recorded correction feedback, review all affected evidence and return corrected source. Completion validates corrections and records new source provenance but leaves the old seal intact. Only the coordinator may deliberately run seal-source --reseal to replace it and invalidate downstream approval; normal source validation intentionally rejects a changed old seal until then. Submitted review pairs are archived, and unchanged resealing cannot reset the cap. Do not edit seals, receipts, state or round counters.
