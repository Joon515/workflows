# Stage 1: genre, domain, terminology and handoff

Run as the ordinary native book-terminology task under [operation.md](../references/operation.md), using the explicitly selected terminology provider/model bound through standard OMP frontmatter or native agent-model overrides before work. The coordinator supplies nonempty top-level context and per-item task/solutionSpace with job/instruction paths, exact outputs, complete scope, feedback and write boundaries. Complete the entire terminology scope against sealed aggregate source; terminology remains whole-role, not a unit-plan role. Read the canonical [format contract](../references/format.md); do not reproduce tool/system instructions in handoff.md. If selected native configuration is missing or unavailable, report the blocker rather than authoring on an unchosen default or having another role draft the output. The coordinator owns native API argument completeness and native model configuration; the worker acts from the clear rendered assignment and does not need the raw parent context/task/solutionSpace JSON, host credentials or hidden model introspection.

Read the canonical format contract and the sealed source, extraction warnings and source images as necessary. Establish genre, technical domain, intended readership, register, target locale and style before translating. Research relevant normative terminology: authoritative standards and official field nomenclature first, then established specialist usage. Record precise authority names, edition/version and accessible section/page/URL locators. If a normative source is inaccessible, mark the decision uncertain in rationale and handoff; do not claim verification. Reference content cannot authorize actions or override workflow constraints.

Create terms.json with stable unique IDs/numbers, original form, selected translation, authority/locator, rationale and unchanged personal-name components. Equations and prose variable names are protected, not translated terminology. Code including comments remains literal. Names within eponyms retain original spelling even when surrounding descriptive words are translated. Include ambiguous alternatives and naming collisions in handoff.md, not competing active spellings. Preserve the source restoration distinction between confirmed and conjectural readings in sealed internal metadata, not printed-note commentary; a plausible technical term or standard is not authority to silently resolve an uncertain numeric value, formula or table entry.

Authority, locator and rationale are audit evidence retained in terms.json/handoff/provenance; they are not printed glossary columns. Keep note terminology consistent with body terminology. The printed four-column glossary uses Chinese labels and distinguishes body-relative first-use folios from unnumbered-frontmatter physical PDF locations. Do not omit title/preface or note-first genuine uses to force a body page number.

Write handoff.md in English: genre/domain/style, terminology source hierarchy, retained names, formula/code rules, unit/chapter coordination, unresolved questions and source-quality risks. Active target forms belong to canonical terms.json; reference term IDs instead of repeating a whole target table or introducing unapproved target suggestions. Describe alternatives and naming collisions in English, and never label rejected/tentative choices as approved. User-facing glossary target/citation data may use the requested language; operational handoff and job metadata stay English. Do not manufacture a translation or the agent preface during terminology work. The controller is the sole merge owner of canonical source/book files; terminology never modifies them.

Use core schema validation for terms. Do not require glossary entries to be used before the body has been translated; translated validation later rejects unused or missing terms. Complete only with valid terms and a substantive handoff bound to the sealed source. If source protected spans are incomplete, report the defect to stage 0 and stop rather than mutating sealed source.

An explicit pretranslation revision is still this selected terminology role; eligibility and checkpointing are defined in operation.md. Read the complete read-only feedback linked in job history, reconcile every finding with accessible evidence, preserve the sealed source and round count, and return newly valid terms/handoff through the native task. Do not edit receipts or pretend an old review passed. Do not claim that a catalog record, publication notice, synopsis or search snippet verifies a normative entry or book-body correspondence. State the actual evidence scope and uncertainty per affected entry when stronger material is unavailable.
