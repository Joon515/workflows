For restoration notes, author only a concise target-language completion notice, preserve the original fragment verbatim and conserve the declared damaged crop at its callout. Do not print a source-page locator, repeated replacement, confirmed/conjectural status, rationale or other commentary; those details remain in immutable internal restoration metadata and evidence for verification. Preserve formula/variable/code/name tokens and genuine image geometry; literal code comments remain unchanged. Select genuine glossary occurrences in the visible scalar title with title_terms annotations defined by the canonical format. The renderer registers annotated title uses before prefaces/body; do not omit them merely because title metadata was previously unformatted. Canonical format owns rendering behavior when an earlier handoff copied an outdated generic rendering description.

Describe genre, terminology policy, machine translation, source/OCR caveats and actual review status without impersonating a human. A human review-translator preface is optional and must only be included when supplied/authorized, not invented. It is a separate section and does not relax the agent-preface cap. Use term tokens for approved terminology in either preface so first-use emphasis and glossary page references cover the whole book, not only the body.

The renderer owns body-start numbering, physical-side running headers, separate source folio annotations, 2-em paragraph/list indentation, source-text-relative preferred image sizing and translated bottom notes. Use the output-only fit contract in format.md only for a necessary, explicitly reviewed uniform downscale of the complete artwork canvas; leave caption and side-text fonts unchanged. Validate and build, then inspect actual pages for header sides/chapter-section state, image/text scale and smallest-detail legibility, absence of blank placeholders, hanging lists, translated note prose, visible restoration completion notice/original fragment/damaged crop without added audit commentary, formula/code/raster-punctuation preservation and note placement. Return complete current authoring and truthful build/page-inspection status; do not hide a failed build or claim an uninspected PDF passed. Only successful controller finalization consumes one review round, even if the next reviewer requests changes. Never hide open findings or mark semantic approval yourself. If the preferred artwork cannot fit a whole eligible page or side column, calculate a candidate bounded uniform downscale allowing for unscaled caption, side text and footnotes, and review its smallest labels/details at the actual compiled size. Record both the explicit scale and its reviewed legibility floor using the canonical fit fields. If it cannot fit at or above that floor, or side text itself is too tall, stop and present the specific conflict for an authorized source/layout decision. Return complete authoring through the prepared native task.
