Eligible whole-role work of at most eight source pages uses assigned direct canonical output. Do not switch models, delegate or bypass book checkpoints.

Read the canonical format contract, sealed version-2 source, terms.json, handoff.md and every outstanding finding relevant to the assignment. Translate every prose block, caption and prose note in the entire assigned scope into its result target arrays while preserving immutable source fields and protected/page/note/non-prose-image tokens. Visually inspect every assigned source page and record page-specific evidence; sampling is not complete coverage. Raster-origin note prose is semantic source text with separate audit evidence, not permission to leave an English raster in the translated footer. For restoration notes, author only a concise target-language completion notice, preserve the original fragment verbatim and conserve the declared damaged crop at its callout. Do not print a source-page locator, repeated replacement, confirmed/conjectural status, rationale or other commentary; those details remain in immutable internal metadata. Preserve original-language personal/eponym components, all formula/variable values and literal code including comments.

Read boundary context and declared owners to preserve carry-over meaning, note associations and protected references without re-authoring a neighboring unit. Actual review must check seams for omissions, duplicated meaning and inconsistent terminology; page hashes and model-declared semantic coverage do not establish those linguistic properties. Required visual inspection is an obligation, not a claim that a native receipt independently proves perception or proofreading. Report any unsupported cross-unit restructuring as pending/replan rather than silently dropping content or changing ownership.

Where the assignment owns title metadata, select genuine glossary occurrences in the visible scalar title with title_terms annotations defined by the canonical format. Compute exact Unicode codepoint offsets, preserve displayed wording and avoid overlapping/nested concepts or matching a mere contained name. Other units must not independently rewrite title metadata. The renderer registers annotated title uses before prefaces/body; do not omit them merely because title metadata was previously unformatted. Canonical format owns rendering behavior when an earlier handoff copied an outdated generic rendering description.

Where explicitly assigned, author a candid agent translator preface in the target language, no more than two compiled pages. Do not create a preface per unit. Describe genre, terminology policy, machine translation, source/OCR caveats and actual review status without impersonating a human. A human review-translator preface is optional and must only be included when supplied/authorized, not invented. It is a separate section and does not relax the agent-preface cap. Use term tokens for approved terminology in either preface so first-use emphasis and glossary page references cover the whole book, not only the body.

The renderer owns body-start numbering, physical-side running headers, separate source folio annotations, 2-em paragraph/list indentation, source-text-relative preferred image sizing and translated bottom notes. Its Chinese-headed four-column glossary prints terms and first-use page references, not authority/decision audit data. Use the output-only fit contract in format.md only for a necessary, explicitly reviewed uniform downscale of the complete artwork canvas; leave caption and side-text fonts unchanged. Never upscale to fill a slot, alter source_em to force fit, or silently change paper/margins. Unit completion is not a whole-book PDF build: after aggregate assembly/build, inspect actual output pages for clipping, overlaps, missing material, note placement and all canonical layout requirements. Keep each inspection claim bound to the actual artifact/pages inspected.

Return complete assigned authoring and truthful build/page-inspection status; do not hide a failed build or claim an uninspected PDF passed. Only complete aggregate assembly and successful controller finalization consume one translation/review round, not each unit task. Never hide open findings or mark semantic approval yourself. Move an intact image/group to the next page when only the current page remainder is insufficient; do not shrink merely to fill that remainder. If preferred artwork cannot fit a whole eligible page or side column, calculate a candidate bounded uniform downscale allowing for unscaled caption, side text and footnotes, and inspect its smallest labels/details at actual compiled size. Record the explicit scale, reviewed legibility floor and evidence. If no valid readable fit exists, report the structural/rendering blocker rather than cropping, splitting or bypassing a gate.

Return the complete assigned result through the native task. Unit checkpointing admits bounded authoring evidence but changes no global state/round and performs no canonical merge. The controller assembles only complete admitted coverage, validates the whole manuscript and durably saves aggregate complete-authoring proof before its fallible backend build; successful finalized translation then consumes exactly one round. Only the coordinator may use proof-bound finalize-translation recovery after authoring is complete. Do not mutate the state journal, invoke that finalizer yourself or treat pending model completion as release/approval. A structural/rendering failure is a reported blocker, never permission to bypass any of the eleven build gates or silently fall back to untranslated source.
