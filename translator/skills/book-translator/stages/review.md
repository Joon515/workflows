# Stage 3: independent review and bounded revision

Run as the prepared book-review native task under [operation.md](../references/operation.md), using the review provider/model explicitly selected for this workflow. Read the canonical [format contract](../references/format.md), source evidence, manuscript, glossary authorities, handoff, build verification and prior findings. Do not repair translation in the reviewer: return precise findings to the selected translation role. Any human input is optional except where source ambiguity or external authority actually requires it.

Review the entire book's semantic coverage, not just compilation or a few fluent excerpts. Compare every block and note to the original, including source-page transitions, OCR errors, omissions, duplication, captions, tables, cross references, mathematical punctuation and citations. Check protected span completeness as well as script-conserved declared spans: an undeclared name or variable can still have been translated incorrectly. Inspect code and comments byte-for-byte against the corrected source. Verify actual standards/locators rather than trusting plausible glossary citations. For each restoration, verify the sealed source-page/callout/replacement association, original fragment, supplied-source crop and corroborating evidence; distinguish confirmed and conjectural readings in the internal metadata. A defensible prose conjecture honestly recorded there is not automatically a defect, but unsupported certainty or unresolved technical values must not pass.

Inspect actual PDF pages, not only TeX/logs: A5 physical-side mirror margins; no translated folio before the explicit main-body boundary and body folio 1 at that boundary; outer running-header folios, left/even inner chapter and right/odd inner section, no footer folio/stale section; separate original-source marks at content transitions; no collision/clipping; first genuine term use styled/numbered and four-column Chinese glossary first-use reference correct for body or frontmatter; no printed authority/decision column. Check source-em preferred image/text scale, panel/side relationships and every explicit fit decision against its reviewed floor. Confirm uniform whole-canvas scaling, no upscale fill, image splitting/cropping or silent paper/margin change; inspect smallest labels, subscripts, rules and panel details at the actual output size. Check 2-em paragraph starts and nested ordered/unordered hanging indentation, and no output for classified source blank pages or invented blank explanations. Inspect every prose note against semantic source and retained original raster evidence: prose must be translated, not passed through as an English footer image. Each restoration note must actually print only a concise target-language completion notice, the verbatim original fragment and the legible declared damage crop. Do not require or add a printed source-page locator, repeated replacement, confirmed/conjectural status, rationale or other commentary; verify those details in sealed internal metadata and evidence instead. Check authored note.target, because the renderer does not generate the visible notice from metadata. Formulas, literal code and names stay protected. Verify note rule/bottom placement/continuation/half-page cap and preface limits. Sparse pages containing real content remain valid. Mechanical gates do not prove semantic completeness, restoration accuracy or legibility.

Before reviewing, capture content_digest and pdf_sha256 from build/verification.json and independently confirm the PDF identity. Write reviews/round-N.json for the current job round with those exact reviewed identities, all eight named checks, exact PDF/source/manuscript locations, findings and inspection evidence. Pass means every check true, no findings, and a current build. A failed check or uncertainty that prevents faithful translation is changes_requested; do not hide it in a passing report. Submission compares the report identities to the current manuscript/PDF before recording a receipt; it must not stamp an old report with newer identities. If either artifact changes during review, inspect the changed artifact again and author a new current report, rather than merely changing the digest fields.

Return the complete current report and all findings through the prepared task. The coordinator must finish and admit native review evidence before submitting that exact report via review; neither task completion nor its receipt auto-submits the report or accepts output. Unreceipted or changed reports cannot be submitted as this review. On changes_requested before the cap, route the entire finding set back to stage 2. At the default third failed translation/review pair, state becomes exhausted and no output.pdf is released. Do not add uncounted retries or expand max_rounds without explicit user choice. On pass, coordinator accept rechecks inputs/build/report before copying output.pdf. Record remaining nonblocking user-facing caveats truthfully; a report is not proof of model compliance, professional certification or measured workflow effectiveness.
