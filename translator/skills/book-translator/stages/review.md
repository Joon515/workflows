# Stage 3: independent review and bounded revision

Run as an ordinary native book-review task under [operation.md](../references/operation.md), using the explicitly selected review provider/model bound through standard OMP frontmatter or native agent-model overrides before work. The coordinator supplies nonempty top-level context and per-item task/solutionSpace with job/instruction paths, exact current artifacts, complete assigned scope, report/result paths, feedback and write boundaries. Read the canonical [format contract](../references/format.md), source evidence, manuscript, glossary authorities, handoff, build verification and prior findings. More than eight source pages requires durable review units. In unit mode write only the assigned review result; the controller alone assembles the complete report. Do not repair translation: return precise findings to the selected translator.

Review planning automatically splits actual output work into at most eight owned physical PDF pages per task, with at most two immediate read-only seam pages. Use every returned unit ID, including deterministic _pdf002/_pdf003 overflow chunks; do not collapse them into one whole-PDF task. Overflow repeats the same bounded source/block/note scope, so source inspections may overlap across review tasks, but physical PDF ownership must remain exact-once and complete. Inspect every source page in the assigned repeated scope and every owned physical PDF page; no sampling, truncation or new public tuning parameter is permitted.

Review semantic coverage throughout the entire assigned scope, not just compilation or a few fluent excerpts. Compare every assigned block and note to the original, including source-page transitions, OCR errors, omissions, duplication, captions, tables, cross references, mathematical punctuation and citations. Check protected-span completeness as well as script-conserved declared spans: an undeclared name or variable can still have been translated incorrectly. Inspect code and comments byte-for-byte against corrected source. Verify actual standards/locators rather than trusting plausible glossary citations. For each restoration, verify the sealed source-page/callout/replacement association, original fragment, supplied-source crop and corroborating evidence; distinguish confirmed readings from documented conjecture, and keep audit metadata out of the printed note. Visually inspect every assigned source page; no coverage-by-sampling claims. Final whole-book coverage requires the aggregate of all admitted scopes, with no missing source pages, blocks, notes or physical PDF pages.

Explicitly reconcile each assigned boundary with read-only neighboring blocks/notes and declared owners: check carry-over sentences, source transitions, notes, images and protected references for missing or duplicated meaning. Hashes, native identity and per-page semantic-ID declarations bind what the model claimed to inspect; they do not independently establish image perception, proofreading, semantic uniqueness or linguistic quality. Inspect every owned source and physical PDF page as required and state actual demonstrated scope separately. Unsupported newly introduced cross-unit structure is a pending/replan blocker, never permission to omit material or report a false pass; do not invent geometric-span annotations.

Inspect every actual PDF page assigned for review, not only TeX/logs, and record physical page identities explicitly. Check A5 physical-side mirror margins; no translated folio before the explicit main-body boundary and body folio 1 at that boundary; outer running-header folios, left/even inner chapter and right/odd inner section, no footer folio/stale section; separate original-source marks at content transitions; no collision/clipping; first genuine term use styled/numbered and four-column Chinese glossary first-use reference correct for body or frontmatter; no printed authority/decision column. Check source-em preferred image/text scale, panel/side relationships and every explicit fit decision against its reviewed floor. Confirm uniform whole-canvas scaling, no upscale fill, image splitting/cropping or silent paper/margin change. Verify translated bottom-note placement, continuation and height limits, restoration output, blank-page omission, lists and preface limits against format.md. A source-page unit alone does not prove coverage of every physical output page; aggregate review must cover both.

Before reviewing, capture content_digest and pdf_sha256 from build/verification.json and independently confirm PDF identity. Write only the assigned report/result with those exact inspected identities, all eight named checks, exact PDF/source/manuscript locations, all findings and page-specific inspection evidence. For a small whole-role run the assigned report is reviews/round-N.json for the current job round; unit runs use the canonical unit result shape/path, not competing writes to that canonical report. Passing the complete book requires every aggregate check true, no findings, complete source and physical PDF coverage, and a current build. A failed check or uncertainty preventing faithful translation is changes_requested; never hide it in a passing report. Submission compares report identities to current manuscript/PDF instead of stamping an old report as current. If an artifact changes, inspect its changed content again and author a new current result.

Return the complete assigned report/result and all findings through the native task. Unit checkpointing does not change global state/round, submit review or accept output. After all required units are admitted and exact source/PDF coverage is assembled, the coordinator must submit the exact aggregate report via review; neither task completion, unit receipts nor assembly auto-submit or accept. Unreceipted, incomplete or changed reports cannot be submitted as this review. On changes_requested before the cap, route the entire aggregate finding set back to stage 2. At the default third failed translation/review pair, state becomes exhausted and no output.pdf is released. Do not add uncounted retries or expand max_rounds without explicit user choice. On pass, coordinator accept rechecks inputs/build/report before copying output.pdf. Record remaining nonblocking user-facing caveats truthfully; a unit pass is not a whole-book approval.
