## Outcome and authority

Produce a complete, accurate translated PDF, not an OCR dump or apparently successful unreviewed build. Establish source ownership/authorization, target language, genre and source quality first. Every workflow needs explicit current-user model choices covering source, terminology, translation and review. An exact current choice already supplied satisfies intake; ask only for missing, unavailable or ambiguous choices. Explicit reuse of current configuration must resolve exact identities. Do not upload private sources or incur unauthorized service charges.

Native OMP owns model resolution, existing registry/authentication, retries, fallback, task settlement and journals. Before source-bearing work configure the four native book agents through standard OMP frontmatter or native agent-model overrides to the user's choices. Portable @task frontmatter is only a conventional template default, not authorization to use an unchosen task model. The translator's configure-model command records book intent, not routing or authentication. Do not build another registry/executor, change global settings or silently relabel a fallback/requested model as actual execution.

The canonical version-2 data and layout contract is format.md. Preserve formulas, variables, literal code including comments and original personal/eponym name components. Default to defensible damaged-prose reconstruction: retain confirmed/conjectural status and supporting evidence in immutable internal metadata, and print only a concise target-language completion notice, the verbatim original fragment and supplied-source damaged crop in the editorial note. Source locator, repeated replacement, status and rationale are not printed commentary. Author the visible notice in note.target; the renderer does not disclose restoration metadata automatically. Never guess ambiguous technical values. Raster prose notes become semantic translated text with non-rendered source evidence, except the required restoration crop. Retain source-em artwork calibration and permit only explicit reviewed bounded uniform downscale, never crop/split/upscale or silent paper/margin changes.

## Stage sequence

0. Follow [source.md](stages/source.md): after model intake/configuration, doctor, init and extract, plan durable bounded units for long books. Ordinary native book-source workers inspect every assigned page and write only assigned results/assets. After actual task settlement the coordinator checkpoints completed book data; the controller assembles full coverage, and the coordinator validates and seals separately. OCR and imported drafts remain pending evidence.
1. Follow [terminology.md](stages/terminology.md): dispatch native book-terminology against complete sealed source to author terms.json and substantive English handoff.md, then checkpoint the whole role.
2. Follow [translation.md](stages/translation.md): dispatch native book-translation on the explicitly selected model. Long books use page-bounded units; title/preface work belongs only to its assigned owner. The controller alone assembles book.json and records complete authoring before build/finalized round advancement. Inspect composed pages before release.
3. Follow [review.md](stages/review.md): dispatch native book-review over every assigned source and actual physical PDF page. Long books require durable review units. The controller assembles complete source/PDF coverage into the exact whole-book report. The coordinator separately submits and accepts only the current passing report/build. Return the entire aggregate finding set on changes_requested. Default three complete translation/review pairs; exhaustion blocks release.

Supply ordinary native task fields: nonempty top-level context and each item's agent, task and solutionSpace. Include exact job/instruction paths, owned scope, packet/result paths, read-only context, feedback and write boundaries. Use native settlement/results, then checkpoint-unit or checkpoint-role with actual flat SingleResult metadata under operation.md. No private run, preparation/finishing protocol, provider capture or package-specific task tools are required. Identity checks record native operator metadata/book progress, not independently proved engine authentication. Preserve actual identities and errors; never synthesize an observed identity from configured intent.

The controller is the single aggregate merge owner. More than eight source pages requires units for source, translation and review; terminology remains whole-role. Source/translation original-page ownership is complete and exact-once, with one to eight owned source pages per unit. Each review task owns at most eight physical PDF pages plus at most two immediate read-only PDF context pages. Automatic overflow repeats bounded source scopes: review source inspection is set-complete, while physical PDF inspection remains exact-once. Workers do not delegate or write sibling/canonical aggregate outputs. A unit checkpoint changes no whole-book state/round and is not release approval.

Hashes and semantic-ID coverage bind model declarations to exact book evidence; they do not independently prove perception, proofreading, semantic uniqueness or translation quality. Inspect every owned source/PDF page and reconcile seams against read-only context and declared owners. Unsupported cross-unit restructuring stays pending for explicit replanning, never silent omission, duplicate authorship or invented geometric-span annotations.

Preserve historical bytes. Explicit import-checkpoints imports only receipt-bound completed legacy book results with hash-linked origins; failed/pending results remain pending and no current native execution is invented. Read [verification.md](references/verification.md) for exercised checks and limits. Resource registration, schema checks, compilation and self-reported review are not independent evidence of translation quality or workflow effectiveness.
