# Durable book contract

This document is the canonical data contract. JSON is UTF-8. Asset paths are relative to the job directory, cannot escape it, and cannot be absolute. Generated artifacts are not authoritative source evidence. All IDs match `[A-Za-z][A-Za-z0-9_-]*`. Version is integer 1.

## Job directory

- `job.json`: `{version:1, title:string, source_language:string, target_language:string, source_file:string, source_sha256:string, max_rounds:3, round:0, state:"initialized", models:{terminology:{provider:string,model:string},translation:{provider:string,model:string}}, layout:{paper:"a5", outer_mm:8, inner_min_mm:20, top_mm:15, bottom_mm:15, source_mark_edge_mm:3}, history:[]}`. States: initialized, extracted, source_ready, terminology_ready, translated, changes_requested, approved, exhausted. The entire inner margin is inner_min_mm; no additional binding compensation is applied. Models must be explicitly set before the respective stage starts. Default three review rounds; each complete translation/review pair consumes one round. An explicit positive max_rounds override is permitted, but never silently expanded.
- `extraction.json`: evidence only, not a ready manuscript; see the extraction contract below.
- `book-source.json`: reviewed source structure, sealed by `source.sha256` before terminology. Immutable after sealing; corrections require explicit resealing and invalidate downstream approval.
- `book.json`: translated manuscript with the same immutable source fields as book-source.json. Only title, target, note target, agent_preface and human_preface may change. It is never silently synthesized from unreviewed OCR.
- `terms.json`: `{version:1, terms:[{id:string, number:positive_integer, source:string, target:string, authority:string, authority_locator:string, rationale:string, protected_ids:[string]}]}`. Numbers and IDs are unique; authority is a relevant standard, normative terminology source or explicit field-consensus evidence. If no standard exists, record the decision and uncertainty, not a fabricated standard. protected_ids identify unchanged names inside this term; target must contain their literal values. Terms used anywhere in the book require table entries; unused table entries are rejected. First use and translated page are derived from actual book reading order, never manually supplied.
- `handoff.md`: stage 1 genre/domain/style/register, authority hierarchy, ambiguous choices, protected names/variables, source-quality caveats and chapter assignments. It is written by the admitted non-OpenAI terminology agent.
- `reviews/round-N.json`: `{version:1, round:N, content_digest:string, pdf_sha256:string, verdict:"pass"|"changes_requested", checks:{coverage:bool, terminology:bool, protected_content:bool, source_pages:bool, image_relations:bool, footnotes:bool, typography:bool, preface:bool}, findings:[{id:string, severity:"blocking"|"major"|"minor", location:string, detail:string}], evidence:[string]}`. content_digest and pdf_sha256 are lowercase SHA256 identities captured from the exact manuscript and PDF inspected by the reviewer, before authoring the report; submission rejects a mismatch instead of relabeling an old report as current. Passing requires every check true and no findings. Evidence identifies inspected PDF pages and extraction/manuscript locations. Submitted pairs are immutable; explicit changed-source resealing archives journal-owned pairs under reviews/archive/ without removing audit history or unrelated files. An unchanged reseal cannot reset the round cap. A record alone cannot prove a model followed the workflow.
- `build/`: generated TeX, PDF, layout evidence and compiler log. Non-OpenAI stage provenance binds the admitted manuscript/content digest, including layout and image inputs; its original compiled-PDF identity is execution evidence, not an authorship requirement for later recompilation of identical content. Current build verification and the author-reviewed report separately bind the exact current PDF bytes. Recompilation may change PDF metadata without changing admitted content; it requires current PDF review, not a new translation round. `output.pdf` is copied only by the final acceptance command after current-input digest and successful review checks.

## Book object

`{version:1, title:string, source_pages:[SourcePage], protected:[Protected], blocks:[Block], notes:[Note], agent_preface:[Inline...], human_preface:null|[Inline...]}`.

SourcePage: `{id:string, locator:string, printed_label:null|string, label_verified:boolean, evidence:string}`. Locator is an extraction page ID, spine location or original image location; NOT an original printed page number. A missing printed number is null. A present label must be transcribed from source evidence and label_verified must be true before source sealing. Roman numbers, prefixes, repeated labels and unnumbered pages are valid. EPUB/MOBI page-list or OCR candidates require provenance review; invented pagination is prohibited.

Protected: `{id:string, kind:"math"|"variable"|"code"|"name", value:string}`. Math/variable values are reviewed LaTeX; code is literal including comments/whitespace; names are literal original spelling. Protected values must survive exactly. No executable TeX commands are permitted in math: input/include/write/read/openout/catcode/csname/special/directlua and similar commands are rejected. Compilation always disables shell escape. A source formula can instead be preserved as an image asset if reliable transcription is unavailable; never replace it with invented LaTeX.

Inline is exactly one of `{text:string}`, `{protected:string}`, `{term:string}`, `{note:string}`, `{page:string}`. A page token marks the exact source-page boundary, including inside a paragraph. Source inline arrays cannot contain term tokens. Target inline arrays must preserve the order and multiplicity of protected, note and page tokens from source. Terms may contain protected name IDs: term expansion counts these IDs toward that invariant. Text translation is the agent's work; scripts cannot establish semantic equivalence or discover every hidden name/variable.

Block common fields: `{id:string, kind:string, source_pages:[string], source:[Inline...], target:[Inline...]}`. Every block must have nonempty source_pages and source evidence. Kinds:

- `heading`: additionally `level:1|2|3`; target rendered as a heading.
- `paragraph`: source and target inline arrays.
- `display_math`: additionally `protected_id:string`; references protected kind math; source/target arrays may be empty and the protected reference is immutable.
- `code`: additionally `protected_id:string`; references protected kind code; rendered verbatim, never translated.
- `image`: additionally `asset:string, width:positive_number, height:positive_number`; dimensions are source pixels/points with consistent units per block, used for aspect ratio. Caption goes in source/target. Image is indivisible.
- `group`: additionally `relation:"row"|"column"|"text-left"|"text-right", images:[{asset:string,x:number,y:number,width:positive_number,height:positive_number}], canvas_width:positive_number, canvas_height:positive_number, text_fraction:number`. Coordinates originate at top left of source crop; preserve relative image geometry, including offsets and gaps. text_fraction is between 0.2 and 0.8 and applies only to side-text groups. For text-left/text-right the source/target text is beside the complete image canvas, not a separately floating paragraph. For row/column it is a caption. Group cannot split across pages. If a side-text group cannot fit a page at a readable scale, block acceptance and ask the agent to revise block boundaries while preserving source relationships; do not crop or silently reorder.

Note: `{id:string, source:[Inline...], target:[Inline...]}`. Exactly one body note reference per note. Notes may contain text, protected and term tokens, but not nested note/page tokens. Notes retain their callout location and become splitting bottom footnotes regardless of original endnote/margin-note placement.

Prefaces are inline arrays limited to text/protected/term tokens; nested note/page tokens are not allowed. agent_preface is required and nonempty for a translated book. human_preface is optional and is not counted toward the agent two-page limit. Agent preface discloses machine translation, terminology choices, source limitations and review status; it must not impersonate a human translator. First-use term formatting and first-output-page references follow actual book reading order: agent preface, optional human preface, then body headings/prose/captions and their notes. Use term tokens for approved terminology in prefaces as well as the body; the appendix lists the first genuine occurrence, not its own generated table entry.

## Extraction contract

`{version:1, input:{path:string,sha256:string,format:string}, pages:[{id:string,locator:string,width:number,height:number,image:null|string,text:string,spans:[{text:string,bbox:[number,number,number,number]}],printed_label_candidates:[{text:string,evidence:string}],ocr:{needed:bool,performed:bool,engine:null|string}}], warnings:[string]}`.

IDs use p0001 etc. Additional extraction evidence fields are allowed: page.assets for embedded image assets, page.image_regions for native image rectangles, and page.ocr.text/spans for OCR separate from native text. Text, spans and page images are evidence, not an automatically approved reading order or correct original page number. Fixed-layout pages retain full rendered source images even if selectable text exists; mixed pages must not skip image-only regions simply because a text layer exists. OCR output is retained separately from original text when both exist, with enough locator information for review. Reflowable EPUB/MOBI render pages are temporary extraction locators, never original page numbers. Embedded images and original archive/source remain available for source-structure reconstruction. OCR may be explicitly required for all pages; missing OCR dependencies fail with actionable errors rather than claiming completion. DRM and unsupported/corrupt inputs fail without circumvention.

## Python module interfaces

All modules live beside `scripts/translator.py`. They use exceptions with actionable English messages and do not print successful completion on failure.

- `extract.py`: `doctor() -> dict`, `extract(source:Path, job_dir:Path, ocr:str="auto", language:str="eng", dpi:int=200) -> dict`. Writes extraction.json and evidence/assets, returns extraction object. OCR policies: auto, always, never. Never records skipped necessary OCR as performed. Native PyMuPDF EPUB/MOBI support is preferred; DjVu requires a real decoder.
- `core.py`: `load_json(path:Path) -> dict`, `save_json(path:Path, value:dict)`, `validate_document(kind:str, value:dict) -> None` for book/terms/job/review schema checks, `validate_book(job_dir:Path, translated:bool=True) -> dict` returns checked book or raises, `seal_source(job_dir:Path) -> str`, `content_digest(job_dir:Path) -> str`, `admit_model(provider:str, model:str) -> str` returns explicit provider/model selector or raises. Validation checks JSON schemas plus semantic invariants and source seal, assets and protected token preservation. Source validation ignores empty translation/preface targets. Terms schema validation permits unused entries until translated-book validation. No settings mutation.
- `render.py`: `render(job_dir:Path) -> Path` writes build/book.tex using validated data; `build(job_dir:Path) -> Path` runs XeLaTeX via latexmk or repeated xelatex, checks dimensions/preface/overflow/references, emits build/verification.json bound to content_digest, returns build/book.pdf. Does not mark semantic approval or copy output.pdf.
- `translator.py`: CLI/controller owns job state and subprocess dispatch. Modules must remain importable from a copied directory without this repository. Tests use unittest and isolated temporary job directories.

## Authority and failure boundaries

Schema validation establishes syntax and selected invariants, not accurate translation, OCR, standards compliance or a truthful review. Source sealing protects accidental downstream edits, not a malicious agent with filesystem access. LaTeX is a program interpreter: source inputs are untrusted; translated text is escaped, assets are constrained, math is conservatively checked, shell escape disabled, and compilation should run in an isolated work directory without secrets. Model restrictions are enforced only at the supplied stage launcher, not across arbitrary direct omp calls. An agent must not bypass that launcher, add fallback models, or delegate stage 1/2 to an unadmitted model. Unknown provider identities fail closed.
